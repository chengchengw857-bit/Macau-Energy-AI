## 🌟 项目亮点 (Highlights)
本项目专为澳门特区复杂工况设计，旨在解决地下停车场寻桩难、跨境补能支付割裂、补能排队时间长等核心痛点。

- 🧠 **AI 智慧补能决策**：根据车辆 SOC 剩余电量、实时路况及峰谷电价，毫秒级生成多目标路径寻优方案。
- 📍 **AR 实景寻桩导航**：针对地下停车场 GPS 弱信号环境，采用视觉惯性里程计 (VIO) 逻辑实现厘米级位置引导。
- 🔋 **创新“换电外卖”服务**：首创能源配送模式，针对澳门老城区无固定车位用户提供“送电上门”闭环体验。
- 🌉 **粤澳一体化互联**：深度整合珠澳跨境充电数据，实现多币种无感支付与漫游补能。

## 🛠 技术栈 (Tech Stack)
- **开发框架**: uni-app (Vue.js 2.x)
- **UI 组件库**: uView UI 2.0 (工业级组件库)
- **底层协议**: 遵循 ISO 15118 (Plug & Charge) 握手协议模拟
- **后端架构**: uniCloud Serverless (Node.js)
